
# Hospital Operations & Patient Management Analytics

## Project Overview
Healthcare Data Analytics project using Python to analyze hospital operations and patient management.

## Objectives
- Analyze patient visits.
- Study waiting times.
- Analyze patient satisfaction.
- Understand department performance.
- Analyze hospital billing.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Findings
- 12,000 visits analyzed.
- Average waiting time: 45.39 minutes.
- Cardiology had the highest average waiting time.
- General Medicine had the highest visit volume.
- Hyderabad had the highest patient visit volume.
